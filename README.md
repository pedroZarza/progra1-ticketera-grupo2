# Sistema de Gestión de Eventos y Entradas

Trabajo práctico de **Algoritmos y Estructuras de Datos I** (UADE, 2do cuatrimestre 2026).

## Descripción

Sistema por consola (CLI) para la gestión de eventos, venues y venta de entradas. Permite administrar lugares y su disponibilidad, crear y publicar eventos, y registrar la compra de tickets por sector o butaca.

## Roles

- **Administrador**: gestiona los venues del sistema y sus sectores/disponibilidad.
- **Organizador**: crea y administra sus propios eventos, precios y disponibilidad.
- **Comprador**: consulta la cartelera, filtra eventos y compra entradas.

## Tecnologías

- Python 3
